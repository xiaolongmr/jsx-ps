# 时间格式选择功能 - 使用指南

## 📌 **什么是时间格式选择？**

脚本现在支持两种时间格式，你可以根据个人或工作习惯选择：
- **24小时制** (国际标准) - 如：14:30:45
- **12小时制** (传统格式) - 如：02:30:45 PM

### 第二步：选择时间格式

**默认是24小时制**，你可以：
- 保持选中 ⭕ **24小时 (14:30:45)** - 推荐，清晰国际化
- 或点击 ⭕ **12小时 (02:30:45 PM)** - 如果习惯这个格式

### 第三步：保存配置（重要！）

设置好时间格式后，务必点击 **"保存配置"** 按钮：

```
日志显示: ✓ 配置已保存！下次打开脚本时将自动加载。
```

这样，下次打开脚本时，你选择的时间格式会自动恢复！

## 💾 **配置保存说明**

### 保存的内容：
```json
{
  "timeFormat": "24h"  // 或 "12h"
  // ... 其他配置
}
```

### 保存位置：
```
Windows: C:\Users\[用户名]\AppData\Roaming\AdobeJSXScripts\AddPageNumbers\config.json
Mac: ~/Library/Application Support/AdobeJSXScripts/AddPageNumbers/config.json
Linux: ~/.AdobeJSXScripts/AddPageNumbers/config.json
```

### 恢复默认值：
如果想恢复到系统默认设置（24小时制），可以：
1. 删除上述config.json文件
2. 或手动编辑，改为 `"timeFormat": "24h"`
3. 重启脚本

## ❓ **常见问题**

**Q: 我改了时间格式但没点"保存配置"，下次打开会怎样？**
A: 会恢复到之前保存的格式。所以一定要点"保存配置"！

**Q: 能在页码中同时显示两种时间格式吗？**
A: 不能。`*time*` 变量只会显示一种格式。但你可以在"页码内容"中手动输入，比如：
```
生成时间：14:30:45 (下午2点30分)
```

**Q: 时间格式是否会影响日期？**
A: 不会。日期 `*date*` 总是 `YYYY-MM-DD` 格式（如 2025-12-14）。只有 `*time*` 受影响。

**Q: 能自定义时间格式吗？**
A: 当前版本不支持。只有这两个标准格式。如有需求，欢迎反馈！
